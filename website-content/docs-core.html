GA-PubSub Core

A lightweight, zero-dependency pub/sub event bus for TypeScript.
Browser · Node.js · Edge · Deno — one API, everywhere.

Introduction

GA-PubSub Core is a publish/subscribe event bus for TypeScript. It lets any part of your application publish named events, and any other part subscribe to them — without tight coupling or a shared reference to a single object.

It works identically in a React SPA, a Node.js microservice, a Cloudflare Worker, and a Deno edge function. No adapter, no polyfill, no platform-specific setup.

Zero dependencies

Pure TypeScript. Ships as ESM + CJS dual build. Nothing extra installed.

Works everywhere

Browser, Node 18+, Deno, Bun, Cloudflare Workers, Vercel Edge.

Wildcards built in

Subscribe to order.* or payments.** — no plugin needed.

Full TypeScript

Generic payloads, strict inference, no any required.

Installation

From a GitHub Release (no registry account needed):

npm install https://github.com/YOUR_ORG/ga-pubsub/releases/latest/download/ga-pubsub-core-1.0.0.tgz

Or from npm if published:

npm install ga-pubsub-core

Tip — Requires Node 18+ or any modern browser. No peer dependencies.

Quick Start

import { EventBus } from 'ga-pubsub-core';

const bus = new EventBus({ namespace: 'my-app' });

// Subscribe to an exact event
bus.subscribe('user.created', (e) => {
  console.log('New user:', e.payload);
});

// Publish
await bus.publish('user.created', { id: '42', name: 'Ajith' });

// Unsubscribe
const handle = bus.subscribe('user.updated', handler);
handle.unsubscribe();

// Tear down
await bus.destroy();

Publish / Subscribe

bus.publish(event, payload, opts?) delivers an event to every matching subscriber in order. It returns a Promise that resolves after all subscribers have been called.

bus.subscribe(pattern, handler, opts?) registers a handler and returns a handle with an unsubscribe() method.

bus.subscribe('order.placed', async (envelope) => {
  const { orderId, total } = envelope.payload as { orderId: string; total: number };
  await sendConfirmationEmail(orderId, total);
});

await bus.publish('order.placed', { orderId: 'ord_001', total: 49.99 });

Envelope shape

Every subscriber receives an EventEnvelope:

FieldTypeDescription
idstringUnique envelope ID (UUID)
eventstringEvent name as published
namespacestringBus namespace
payloadunknownData passed to publish()
timestampnumberUnix ms at publish time
sourcestringBus source identifier
correlationIdstringShared across a request chain
causationIdstringID of the triggering envelope
ttlnumber?Milliseconds until expiry

Wildcards

Patterns support two wildcard tokens:

TokenMatchesExample patternMatches
*Exactly one segmentorder.*order.created, order.cancelled
**One or more segmentspayments.**payments.card.charged, payments.refund.issued
// Matches order.created, order.updated, order.cancelled
bus.subscribe('order.*', handler);

// Matches any event one or more levels beneath payments.
bus.subscribe('payments.**', handler);

// Mixed
bus.subscribe('app.*.error', handler);

Note — a.** does not match a alone. The dot separator requires at least one trailing segment.

Priority Ordering

Subscribers on the same event run in descending priority order. Default priority is 0.

bus.subscribe('payment.received', auditLog,      { priority: 10 }); // runs first
bus.subscribe('payment.received', sendReceipt,   { priority: 5  });
bus.subscribe('payment.received', updateMetrics, { priority: 1  }); // runs last

subscribeOnce

Fires exactly once then removes itself automatically.

bus.subscribeOnce('app.ready', (e) => {
  console.log('App started at', e.timestamp);
});

Middleware

Middleware functions intercept every event before subscribers are called. They run in registration order and must call next() to continue the chain.

// Enrich every envelope
bus.use(async (envelope, next) => {
  (envelope as any).payload = { ...envelope.payload as object, processedAt: Date.now() };
  await next();
});

// Abort — throws MiddlewareAbortError, subscribers never run
bus.use(async (envelope, next) => {
  if (isBanned(envelope.source)) throw new MiddlewareAbortError(envelope.event);
  await next();
});

Built-in middleware

import { loggingMiddleware, ttlGuardMiddleware } from 'ga-pubsub-core';

bus.use(loggingMiddleware({ level: 'debug' }));
bus.use(ttlGuardMiddleware());

Schema Validation

Register a validator for an event name. Invalid payloads throw ValidationFailedError before any subscriber is called.

bus.registerSchema('order.placed', {
  name: 'OrderSchema',
  validate: (payload) => {
    const p = payload as { orderId?: unknown; total?: unknown };
    if (typeof p.orderId !== 'string')
      return { valid: false, errors: [{ path: 'orderId', message: 'required string' }] };
    if (typeof p.total !== 'number')
      return { valid: false, errors: [{ path: 'total', message: 'required number' }] };
    return { valid: true };
  },
});

// Throws ValidationFailedError — orderId must be a string
await bus.publish('order.placed', { orderId: 123, total: 49.99 });

Works with any validator — Zod, Yup, or custom. Just return { valid: true } or { valid: false, errors }.

Request / Response (RPC)

bus.request() sends an event and awaits a single response from a registered bus.respond() handler. Times out if no handler responds within timeoutMs.

// Responder (register once, usually at startup)
bus.respond<{ a: number; b: number }, { result: number }>(
  'math.add',
  (e) => ({ result: e.payload.a + e.payload.b })
);

// Requester
const { response, cancel } = bus.request<
  { a: number; b: number },
  { result: number }
>('math.add', { a: 3, b: 7 }, { timeoutMs: 2000 });

const env = await response;
console.log(env.payload.result); // 10

// Cancel if needed
cancel();

Replay Engine

When replay is enabled, late subscribers automatically receive previously published events from a configurable ring buffer.

const bus = new EventBus({
  replay: { limit: 100, replayWildcards: true }
});

await bus.publish('app.started', { version: '2.0' });
await bus.publish('app.configured', { theme: 'dark' });

// Late subscriber — receives both replayed events immediately
bus.subscribe('app.*', (e) => console.log('replayed:', e.event));

// Opt out of replay for a specific subscription
bus.subscribe('app.*', handler, { replay: false });

TTL Guard

Publish with a ttl (milliseconds). The built-in ttlGuardMiddleware silently drops the event if it arrives at a subscriber after the TTL has elapsed.

bus.use(ttlGuardMiddleware());

await bus.publish('cache.invalidate', { key: 'user:42' }, { ttl: 5000 });
// Dropped if delivered more than 5 seconds after publish

Metrics

const m = bus.getMetrics();

m.publishCount        // total events published
m.deliveryCount       // total successful deliveries
m.failureCount        // subscriber errors
m.authDenialCount     // authorization denials
m.activeSubscriptions // current live subscriptions
m.p95LatencyMs        // p95 delivery latency over last 1000 events
