WHAT IS GA-PUBSUB?
------------------
GA-PubSub is a publish/subscribe event bus built for modern TypeScript projects.
It lets different parts of your application communicate through named events —
without tight coupling, without a message broker, and without any server
infrastructure.

Publish an event from one place. Subscribe to it anywhere else. Wildcards,
middleware, schema validation, replay, and RPC come built in. It just works.


FEATURES
--------
Pub / Sub
Subscribe to exact event names or wildcard patterns. order.* matches
order.created, order.updated, and order.cancelled. payments.** matches any
depth beneath the payments namespace.

Priority Ordering
Multiple subscribers on the same event run in priority order — highest first.
Critical handlers always execute before lower-priority ones.

subscribeOnce
Register a handler that fires exactly once and then removes itself automatically.
No cleanup code needed.

Middleware Pipeline
Intercept, enrich, transform, or abort events before they reach subscribers.
Add logging, validation enrichment, or custom filtering as composable steps.

Schema Validation
Register a validator for any event name. Invalid payloads throw a
ValidationFailedError before any subscriber is called. Integrate with Zod,
Yup, or any custom validator.

Request / Response (RPC)
bus.request() sends an event and waits for a response from the first
bus.respond() handler. Configurable timeout. Perfect for service-to-service
calls inside a single process.

Replay Engine
Late subscribers automatically receive previously published events from a
configurable ring buffer. Wildcard-aware. Opt-out per subscription.

TTL Guard Middleware
Events with an expired time-to-live are silently dropped before reaching
subscribers. Pass ttl in milliseconds when publishing.

Metrics
Built-in counters for publish count, delivery count, failure count, auth
denials, and p95 delivery latency. No external monitoring agent required.

Subscription Limit
Set a maximum number of active subscriptions per bus instance to prevent
runaway listener accumulation in long-running processes.

Cancel In-Flight Requests
Call handle.cancel() on any pending request to immediately reject the response
promise. No dangling timers.


INSTALLATION
------------
From GitHub Releases (no npm account needed):

  npm install https://github.com/YOUR_ORG/ga-pubsub/releases/latest/download/ga-pubsub-core-1.0.0.tgz

Or from npm (if published):

  npm install ga-pubsub-core


QUICK EXAMPLE
-------------
  import { EventBus } from 'ga-pubsub-core';

  const bus = new EventBus({ namespace: 'my-app' });

  bus.subscribe('user.created', (e) => {
    console.log('New user:', e.payload);
  });

  await bus.publish('user.created', { id: '42', name: 'Ajith' });

  // Wildcard — fires for user.created, user.updated, user.deleted ...
  bus.subscribe('user.*', (e) => console.log(e.event, e.payload));
