GA-PubSub Pro

Enterprise pub/sub — HMAC signing, rate limiting, authorization,
replay-attack prevention, multi-tenancy, and transport adapters.

Introduction

GA-PubSub Pro extends GA-PubSub Core with the security and infrastructure features that production systems require. Every PRO feature is opt-in — you enable only what you need. Everything from the Core works exactly as documented in the Core docs.

🔐

HMAC Signing

Sign every envelope. Detect tampering instantly on inbound transport messages.

⏱️

Rate Limiting

Token-bucket per source. Configurable burst capacity. Throws on violation.

🔒

Authorization

Pattern-based authorizers with wildcard support. Per-event, per-user rules.

🛡️

Replay Prevention

Monotonic sequence enforcement. Duplicate or rewound envelopes are rejected.

🏢

Multi-Tenancy

Isolated namespace registry. One bus per tenant, zero cross-tenant leakage.

🔌

Transport Adapters

Redis, Kafka, WebSocket, NATS, RabbitMQ — plug in any broker.

Installation

PRO is distributed via private GitHub Release. You receive access to the private repository when you purchase a license.

# Install from a pinned release tag (recommended)
npm install github:YOUR_ORG/ga-pubsub-pro#pro-v1.0.0

# Or directly from the release tarball URL
npm install https://github.com/YOUR_ORG/ga-pubsub-pro/releases/download/pro-v1.0.0/ga-pubsub-pro-1.0.0.tgz

Also install the Core package, which PRO depends on:

npm install ga-pubsub-core

Drop-in Upgrade

If you are upgrading from Core, change the import. Nothing else in your code needs to change — ProEventBus is exported as EventBus from ga-pubsub-pro.

// Before (Core)
import { EventBus } from 'ga-pubsub-core';

// After (PRO) — identical API, PRO features added via constructor options
import { EventBus } from 'ga-pubsub-pro';

const bus = new EventBus({
  namespace: 'my-app',
  licenseKey: process.env.GA_PUBSUB_LICENSE_KEY,
  enableSigning: true,
  signingSecret: process.env.SIGNING_SECRET,
  rateLimit: 100,
});

License Key Setup

Every PRO instance requires a valid license key in production. The key is validated offline on the first publish() call using HMAC-SHA256 — no internet connection or license server is contacted.

import { ProEventBus } from 'ga-pubsub-pro';

const bus = new ProEventBus({
  namespace: 'production',
  // Pass via environment variable — never hardcode
  licenseKey: process.env.GA_PUBSUB_LICENSE_KEY,
});

Security — Store your license key in a server-side environment variable only. Never include it in a browser bundle, client-side code, or commit it to version control.

You can inspect the validated license info after the first publish:

await bus.publish('app.started', {});
const info = bus.getLicenseInfo();
console.log(info?.plan);          // 'professional'
console.log(info?.daysUntilExpiry); // e.g. 312

Expiry warning — GA-PubSub Pro logs a console warning 30 days before your key expires. Renew at deslay-ai.web.app/ga-pubsub-pro/queries.

HMAC Envelope Signing

When enabled, every published envelope is signed with HMAC-SHA256 before delivery. Inbound transport messages are verified before being dispatched to local subscribers — a single tampered byte throws TamperDetectedError.

const bus = new ProEventBus({
  enableSigning:    true,
  signingSecret:    process.env.SIGNING_SECRET,
  verifySignatures: true, // verify inbound transport messages
});

// Sign and verify manually (e.g. for custom transport adapters)
import { signEnvelope, verifyEnvelope } from 'ga-pubsub-pro';

const sig     = await signEnvelope(envelope, secret);
const isValid = await verifyEnvelope(envelope, secret);

Tip — Signing uses the Web Crypto API, which is available natively in Node 18+, all modern browsers, Deno, and Cloudflare Workers. No crypto library dependency needed.

Rate Limiting

Token-bucket rate limiting per source. Set rateLimit to the sustained events-per-second cap. rateLimitBurst controls the burst capacity (defaults to rateLimit × 2).

const bus = new ProEventBus({
  rateLimit:      100,  // 100 events/sec sustained
  rateLimitBurst: 150,  // allow short bursts up to 150
  source:         'order-service',
});

// Throws RateLimitExceededError when the bucket is empty
await bus.publish('order.created', payload);

Rate limiting is tracked per source string — different publishers are metered independently.

Using RateLimiter directly

import { RateLimiter } from 'ga-pubsub-pro';

const limiter = new RateLimiter(50, 80); // 50/s, burst 80
limiter.consume('my-service');          // throws if exceeded

Authorization

Register authorizer functions per event pattern. Authorizers receive the full envelope and an AuthContext. Return true to allow, false to deny.

bus.authorize('admin.**', (envelope, ctx) => {
  return ctx.roles?.includes('admin') ?? false;
});

bus.authorize('user.*', (envelope, ctx) => {
  return ctx.userId !== undefined;
});

// Publish with auth context
await bus.publish('admin.settings.updated', payload, {
  userId: 'u_42',
  metadata: { roles: ['admin'] },
});

AuthContext shape

FieldTypeDescription
userIdstring?Authenticated user ID
rolesstring[]?Role list (e.g. ['admin', 'editor'])
permissionsstring[]?Permission strings
tenantIdstring?Tenant identifier for multi-tenant setups
claimsRecord<string, unknown>?Arbitrary JWT claims or custom data

Replay-Attack Prevention

Envelopes carry a monotonic sequence number per source. Inbound transport messages are checked against a SequenceTracker — duplicated or rewound sequences throw ReplayAttackError.

const bus = new ProEventBus({
  enableReplayPrevention: true,
});

// Use SequenceTracker standalone
import { SequenceTracker } from 'ga-pubsub-pro';

const tracker = new SequenceTracker();
tracker.check(envelope); // throws ReplayAttackError if replayed

Payload Size Enforcement

Enforces a maximum serialised payload size in bytes before any subscriber runs. Default is 64 KB. Set to 0 to disable.

const bus = new ProEventBus({
  maxPayloadBytes: 32_768, // 32 KB custom limit
});

// Enforce on a single envelope without a full bus
import { enforcePayloadLimit } from 'ga-pubsub-pro';
enforcePayloadLimit('order.placed', payload, 65_536);

Multi-Tenant Namespace Registry

getBus(namespace) returns a singleton ProEventBus per namespace string. Namespaces are fully isolated — subscribers in one namespace never receive events from another.

import { getBus, listNamespaces, destroyNamespace, destroyAll } from 'ga-pubsub-pro';

// Each tenant gets its own isolated bus
const acmeBus  = getBus('acme-corp');
const globeBus = getBus('globex-inc');

acmeBus.subscribe('order.placed', handleOrder);
// globeBus subscribers never receive acme events

// Lifecycle management
listNamespaces();           // ['acme-corp', 'globex-inc']
await destroyNamespace('acme-corp');
await destroyAll();

Scoped Bus

createScopedBus(bus, prefix) returns a ScopedBus that auto-prepends the prefix to every publish and subscribe call. Multiple scopes on the same bus are independent.

import { ProEventBus, createScopedBus } from 'ga-pubsub-pro';

const root     = new ProEventBus({ namespace: 'app' });
const orders   = createScopedBus(root, 'orders');
const payments = createScopedBus(root, 'payments');

// publishes as 'orders.created'
await orders.publish('created', { orderId: '001' });

// subscribes to 'payments.charged'
payments.subscribe('charged', handler);

Transport Adapters

Connect ProEventBus to an external message broker by implementing the TransportAdapter interface and passing it to the constructor. Inbound messages are HMAC-verified and replay-checked before dispatch.

import type { TransportAdapter, EventEnvelope } from 'ga-pubsub-pro';

class MyRedisAdapter implements TransportAdapter {
  readonly name = 'redis';
  async connect() { /* connect to Redis */ }
  async disconnect() { /* clean up */ }
  async publish(env: EventEnvelope) { /* publish to Redis channel */ }
  async subscribe(pattern: string, cb: (env: EventEnvelope) => void) {
    /* subscribe to Redis pattern, call cb on message */
    return () => { /* unsubscribe */ };
  }
  async ping() { return true; }
  on(event: string, handler: (...args: unknown[]) => void) {}
  off(event: string, handler: (...args: unknown[]) => void) {}
}

const bus = new ProEventBus({
  transport: new MyRedisAdapter(),
  enableSigning:    true,
  verifySignatures: true,
  signingSecret:    process.env.SIGNING_SECRET,
});

License Key Errors

All license errors extend LicenseError and carry a code field.

MISSING_KEY

No license key provided.

Fix: Pass licenseKey: process.env.GA_PUBSUB_LICENSE_KEY to the constructor. Purchase at deslay-ai.web.app/ga-pubsub-pro.

INVALID_FORMAT

Key string does not match expected format.

Fix: Copy the key exactly as issued — no spaces, no line breaks, no truncation. Keys start with lk_.

INVALID_SIGNATURE

HMAC signature mismatch — key was altered or corrupted.

Fix: Do not modify the key. Request a replacement at deslay-ai.web.app/ga-pubsub-pro/queries.

EXPIRED

License key expiry date has passed.

Fix: Renew your key at deslay-ai.web.app/ga-pubsub-pro/queries. A 30-day warning is logged before expiry.
