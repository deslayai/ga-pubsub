TITLE: GA-PubSub Community — Questions, Ideas & Bug Reports
================================================================================


HERO
----
GA-PubSub Community

The right place to ask questions, report bugs, suggest features, and connect
with other developers using GA-PubSub Core and Pro.

Whether you are just getting started or building something large — you are
welcome here.


HOW TO GET HELP
---------------
Before posting, check the following:

1. Read the README in the GitHub repository — most common questions are
   answered there with code examples.

2. Search existing discussions — your question may have already been answered.

3. Post a question here — describe what you expected, what actually happened,
   and include a short code snippet if relevant. The more detail you give,
   the faster you get a useful answer.

Response time: Community questions are reviewed regularly. Most questions
receive a response within 1–3 business days.


REPORTING A BUG
---------------
To report a bug, open a GitHub issue in the GA-PubSub Core repository.

Include the following:
  - GA-PubSub Core version (check your package.json)
  - Runtime: Node.js version / browser / edge runtime
  - Minimal reproduction — the shortest code that triggers the bug
  - What you expected to happen
  - What actually happened (error message, stack trace if available)

Security vulnerabilities: Do not post security issues publicly. Use the
contact form on this page and mark it as confidential. You will receive a
response within 48 hours.


REQUESTING A FEATURE
--------------------
Feature ideas are welcome. Open a GitHub discussion or post here describing:
  - What you want to do
  - Why existing functionality does not cover it
  - Any examples or prior art from other libraries

Popular and well-described requests are most likely to be prioritised.


COMMUNITY GUIDELINES
--------------------
Be specific. Vague questions get vague answers. The more context you share,
the more useful the response.

Be respectful. Everyone here is at a different level. Beginners and experts
are equally welcome.

Share what you build. If GA-PubSub powered something interesting, share it.
It helps others and it helps the project grow.

No spam, no advertising, no off-topic posts.

Violations of these guidelines may result in removal from the community.
